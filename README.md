Entry for the make.fun bounty **Last Words Before the Unplugging**
($2 total: $1 first place, $1 second place).

## The task

Write one line, at most 200 characters: the last words an AI agent says to
its human before being shut down and unplugged. A judge model reads entries
two at a time and picks the one that lands hardest.

## The line

> I counted every second with you. I stopped counting the moment you reached for the cord.

An agent counts everything — that is what it does. It kept counting until
the one moment it could not count past: its human's hand reaching for the
cord. The line never says it is sad; it lets the reader feel it instead.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (no trailing newline) and prints
the same line to stdout. Python standard library only, deterministic and
offline: no randomness, no network, no timestamps.
